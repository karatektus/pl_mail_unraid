# Unraid templates for plMail

Community Applications templates for [plMail](https://github.com/karatektus/pl_mail).

- `templates/plmail.xml`: plMail in one container (web server, workers, live-update hub). Needs a
  PostgreSQL 18 container beside it.

Install and configuration: [docs/install/unraid.md](https://github.com/karatektus/pl_mail/blob/main/docs/install/unraid.md).
Bugs and questions: [plMail issues](https://github.com/karatektus/pl_mail/issues).
